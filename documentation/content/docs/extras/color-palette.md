# Color palette

For simple particles used in various places (e.g. the bullet impact particles) Half-Life utilizes the predefined color palette. For the most part it's the same as [Quake palette](https://quakewiki.org/wiki/Quake_palette) with a notable exception being the color 244 which is pure green in Half-Life (`#00FF00` or `0 255 0`).

This means the particles can't have the exact RGB values for their color. Instead the game will try to pick the closest color from the palette.
