# ![](/images/spirit.png) trigger_motion

Syncs a motion of one entity with another one time per activation.

See [motion_manager]({{< ref motion_manager >}}) for continuous syncing.

### Parameters

* `Target to affect [LE]` - entity to apply motion to. Only the first found entity is affected.
* `Position (blank = no change)` - new position of the entity.
* `Angles (blank = no change)` - new angles on the entity.
* `Velocity (blank = no change)` - new velocity of the entity.
* `AVelocity (blank = no change)` - new angular velocity of the entity.
