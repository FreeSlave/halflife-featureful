# multi_trigger

An alternative to [multi_manager]({{< ref multi_manager >}}) with a different interface. Instead of expecting the mapper to add targets manually, the `multi_trigger` provides targets and delays as separate parameters. This allows to show connections to the target entities in J.A.C.K. If you don't use this feature in the editor, you may just use `multi_manager` as usual.

The delay parameters support the same way of setting the use-type as `multi_manager` does.
