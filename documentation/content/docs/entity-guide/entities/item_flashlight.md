# item_flashlight

A pickable flashlight. This can be picked up separately from the [item_suit]({{< ref item_suit >}}) to provide the flashlight without giving player the HEV suit, or if `item_suit` doesn't provide flashlight by itself (`suit_light` server feature is set to false).

The item uses **models/w_flashlight.mdl** model from Blue Shift.

### Soundscripts

* **Flashlight.Pickup** flashlight is getting picked up. Derived from **Item.Pickup**
