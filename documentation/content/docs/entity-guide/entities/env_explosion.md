# env_explosion

[TWHL](https://twhl.info/wiki/page/env_explosion)

### New parameters

* ![](/images/spirit.png) `Initial position` - a dynamic explosion position.
* `Fireball Sprite` - custom explosion sprite.
* `Custom sprite scale` - custom explosion sprite scale.
* `Custom Smoke Sprite` custom smoke sprite.

### New spawnflags

* `No sound` - prevent playing an explosion sound.
* `Activator is attacker` - send the entity's activator as an attacker when dealing damage (e.g. to make monsters angry at the activator).
