# env_splash

Upon triggering, creates a particle splash similar to one created by `target_splash` entity from Quake II.

This can be used as an alternative for spark visual effect or as a water splash.

The direction of splash depends on the entity angle.

{{% hint warning %}}
It's recommended to have the **sprites/dot_index.spr** sprite present in the game files (distributed with the sample mod).
{{% /hint %}}
