# func_breakable_effect

Invisible non-solid brush entity that can be triggered to create the same effect as from breaking the [func_breakable]({{< ref func_breakable >}}), i.e. sounds and gibs.

Set the `Repeatable` spawnflag and `At position` parameter to allow the effect to be reused multiple times and in different places.
