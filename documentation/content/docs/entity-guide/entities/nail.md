# nail

### Skill variables

* **sk_nail** - nail damage.
* **sk_plr_nail** - nail damage dealt by player's nailgun.

### Soundscripts

* **Nail.HitBody** - plays with 50% chance when hiting something that can take damage.
* **Nail.HitWall** - plays with 50% chance when hitting something that can't take damage.

### Visuals

* **Nail.Model** - nail itsef.
