# ![](/images/opfor.png) monster_penguin

Similar to [snark]({{< ref monster_snark >}}) but detonates like a grenade.

### Skill variables

* **sk_snark_health** - monster's health.
* **sk_snark_dmg_bite** - bite damage.
* **sk_plr_hand_grenade** - the base explosion damage. Each bite insreases the explosion damage by the same number.

### Default classification

`Snark`

### Soundscripts

Uses same soundscripts as [monster_snark]({{< ref monster_snark >}}).
