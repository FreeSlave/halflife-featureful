# weapon_pistol2

Same as [weapon_pistol]({{< ref weapon_pistol >}}) but uses a different classname, so it's a different weapon.

{{% hint info %}}
Don't forget to include **sprites/weapon_pistol2.txt** in your mod files.

Also enable `pistol2` in **features/featureful_weapons.cfg**.

Configure the weapon HUD position via **features/hud_weapon_layout.cfg**.
{{% /hint %}}
