`Alien Monster`

* **Ichthyosaur.Idle** - idle sounds.
* **Ichthyosaur.Alert** - alert sounds.

* **Ichthyosaur.Die** - death sounds.
* **Ichthyosaur.Attack** - starting chasing the enemy.
