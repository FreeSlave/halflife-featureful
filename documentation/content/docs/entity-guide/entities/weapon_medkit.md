# ![](/images/svencoop.png) weapon_medkit

A portable medkit that can heal allies, similar to one from Sven Co-op and Team Fortress Classic. The charge can be replenished by picking up healthkits and using wall mounted health chargers when player is on full health.

Secondary attack heals the owner.

Sven Co-op like revival is not implemented.

### Skill variables

* **sk_plr_medkitshot** - healing per use.
* **sk_plr_medkittime** - recharge interval, in seconds (currently only for multiplayer).
