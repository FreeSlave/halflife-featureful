# item_sodacan

[TWHL](https://twhl.info/wiki/page/item_sodacan)

### Skill variables

* **sk_soda** - amount of health recovered by soda can. In Half-Life it's hardcoded as 1 for all difficulties.

### Soundscripts

* **ItemSoda.Bounce** - played shortly after the soda gets spawned.
* **ItemSoda.Drink** - soda can is picked up by a player. Empty by default.
