# ![](/images/opfor.png) weapon_displacer

The displacer weapon that allows to teleport to the [info_displacer_xen_target]({{< ref info_displacer_xen_target >}}) entity.

The primary attack fires [displacer_ball]({{< ref displacer_ball >}}) projectile.

After teleportation the gravity for the player automatically sets to half of the base gravity.

### Skill variables

* **sk_plr_displacer_other** - displacer ball damage amount.
* **sk_plr_displacer_radius** - displacer ball damage radius.
