# trigger_changetarget

[TWHL](https://twhl.info/wiki/page/trigger_changetarget)

### Changes

* Supports `!activator` for `Entity to affect`.
* Supports `!activator` for `New Target` - this will set the entity's `target` to the activator's `targetname` (this might be empty is the activator doesn't have a targetname).
