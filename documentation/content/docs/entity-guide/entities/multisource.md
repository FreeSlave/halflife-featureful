# multisource

[TWHL](https://twhl.info/wiki/page/multisource)

If you're just looking for the [master]({{< ref "master-entities" >}}) capabilities (to block a trigger or lock a door) you may use a simpler alternative like [env_state]({{< ref env_state >}}).

The `multisource` is still good for tasks that require things like checking whether several buttons are pressed at the same time.
