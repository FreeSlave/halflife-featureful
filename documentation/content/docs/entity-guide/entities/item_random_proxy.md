# item_random_proxy

Spawns a random item using the list from specified [info_item_random]({{< ref info_item_random >}}). If entity has a targetname, it needs to be triggered in order to spawn a random item.

### Parameters

* `info_item_random entity` - name of the [info_item_random]({{< ref info_item_random >}}) entity to select an item from.
