# player_weaponstrip

[TWHL](https://twhl.info/wiki/page/player_weaponstrip)

Removes all player's weapons and optionally other player's items.

### New spawnflags

* ![](/images/svencoop.png) `Remove suit` - remove player's suit. The flashlight or nvg will be removed only if suit comes with one of them by default. Otherwise the `Remove flashlight/nvg` flag should be checked too.
* `Remove flashlight/nvg` - remove the light item.
* `Remove longjump` - remove longjump item.
* `Remove inventory items` - remove [player inventory items]({{< ref player-inventory >}}).
* `Remove canisters` - remove antidotes, radiation canisters and adrenalines.
