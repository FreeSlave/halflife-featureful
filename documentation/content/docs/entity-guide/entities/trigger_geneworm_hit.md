# ![](/images/opfor.png) trigger_geneworm_hit

Similar to [trigger_hurt]({{< ref trigger_hurt >}}), but does damage depending on the **sk_geneworm_dmg_hit** variable and also plays the attack sound.

This entity is used in the [Geneworm]({{< ref monster_geneworm >}}) chamber in Opposing Force.

### Soundscripts

* **GeneWorm.AttackHit** - melee attack hit. Derived from **NPC.AttackHit**.
