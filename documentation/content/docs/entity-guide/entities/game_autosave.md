# game_autosave

Point entity alternative to [trigger_autosave]({{< ref trigger_autosave >}}). This entity should have a name and must be triggered in order to create an autosave.

See also: [Autosave message]({{< ref "text-messages/#autosave" >}})

### Parameters

* `Minimum Hit Points` - don't save the game when player has less than this many hitpoints.
