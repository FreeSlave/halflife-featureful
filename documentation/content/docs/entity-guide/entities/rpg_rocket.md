# rpg_rocket

The rocket entity shot by player's RPG or by `func_tankrocket`.

### Skill variables

* **sk_plr_rpg** - rocket explosion damage.

### Soundscripts

* **RPG.RocketIgnite** - rocket travel sound. Must be looped.

### Visuals

* **RPG.Trail** - trailing beam.
