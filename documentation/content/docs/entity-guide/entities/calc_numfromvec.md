# ![](/images/spirit.png) calc_numfromvec

Calculates a single numeric value from the vector. Can retrieve a certain component or calculate the length of the vector.

### Differences from SoHL version

* Allows to select the base vector type (Locus Velocity, Locus Position or rendercolor of the entity). Original entity supports only Locus Velocity.
* "Swizzle" parameters are not supported.

### Calc Ratio

Reports the value retrieved or calculated from the base vector.
