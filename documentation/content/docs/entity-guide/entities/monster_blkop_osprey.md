# ![](/images/opfor.png) monster_blkop_osprey

Blackops Osprey aircraft. Uses same parameters, skill variables, soundscripts and visuals as [monster_osprey]({{< ref monster_osprey >}}).

Behaves the same way as regular Osprey, but deploys male assassins instead of human grunts.

### Default classification

`Machine` or `Blackops` if `blackops_classify` server feature is enabled.
