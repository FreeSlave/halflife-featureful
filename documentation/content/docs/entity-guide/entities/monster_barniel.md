# monster_barniel

Female version of [monster_barney]({{< ref monster_barney >}}) from Azure Sheep. Uses `BN` prefix for sentences instead of `BA`.

### Skill variables

* **sk_barney_health** - monster's health.
* **sk_9mm_bullet** - handgun bullet damage.

### Default classification

`Player Ally`

### Default display name

`Security Guard`

### Soundscripts

* **Barniel.Pain** - pain sound.
* **Barniel.Die** - death sound.
* **Barniel.FirePistol** - firing a handgun.
