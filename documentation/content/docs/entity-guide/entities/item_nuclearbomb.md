# ![](/images/opfor.png) item_nuclearbomb

A nuclear bomb device planted by Blackops in Opposing Force.

This basically acts as a toggle button. While On, it's playing the ticking sound.

The bomb consists of three models: the bomb case, the timer and the button. While the bomb is on, the timer is playing the ticking sound and changes its skin between 0, 1 and 2.

### Soundscripts

* **NuclearBomb.Off** - turning off.
* **NuclearBomb.On** - turning on.
* **NuclearBomb.Ticking** - ticking sound, when on.

### Visuals

* **NuclearBomb.Timer** - the timer model. Expects to have 4 skins (0-3).
* **NuclearBomb.Button** - the button model. Expects to have 2 skins (for off and on states).
