# ![](/images/spirit.png) calc_position

Calculates a position value based on the position of another entity. Can be used in `LP` parameters.

{{% hint danger %}}
Retrieving *Attachment point* position is allowed only from animated entities (e.g. monsters, `item_generic` and `env_model`)
{{% /hint %}}
