# ![](/images/opfor.png) monster_houndeye_dead

Dead houndeye. If the **models/houndeye_dead.mdl** model (from Opposing Force) exists in the mod files and the pose is set to `dead`, the **models/houndeye_dead.mdl** will be set by default. Otherwise the standard **models/houndeye.mdl** will be used with one of the dying animations on the last frame.
