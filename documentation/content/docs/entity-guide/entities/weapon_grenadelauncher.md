# ![](/images/tfc.png) weapon_grenadelauncher

Grenade launcher from Team Fortress Classic. By default grenade launcher uses `grenades` ammo type which shouldn't be confused with `Hand Grenade` and `ARgrenades`.

{{% hint info %}}
As Team Fortress Classic is missing the `w_` models for weapons, this weapon is using thee **w_weaponbox.mdl** for the world model by default.
{{% /hint %}}
