# info_item_random

Template for [item_random_proxy]({{< ref item_random_proxy >}}). Similar to [item_random]({{< ref item_random >}}) it provides a list of items and their spawn probabilities, but unlike `item_random`, `info_item_random` can be reused multiple times by either `item_random_proxy` or [func_breakable]({{< ref func_breakable >}}).

This entity doesn't need to be called. It just needs to be present on the map so other entities could find it.
