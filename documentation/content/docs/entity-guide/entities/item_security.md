# item_security

[TWHL](https://twhl.info/wiki/page/item_security)

### New parameters

* `Message` - show message from titles.txt on pickup.
* `Pickup sound` - sound played on pickup.
* `HUD name` - sprite from hud.txt to show on pickup. By default it won't show anything.
