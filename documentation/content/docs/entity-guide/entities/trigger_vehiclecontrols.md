# trigger_vehiclecontrols

Enables or disables the controls for targetted [func_tracktrain]({{< ref func_tracktrain >}}) or [func_vehicle]({{< ref func_vehicle >}}). The target must be the name of train or vehicle.

### Reaction to use-type

The use-type tells what to do with vehicle controls.
