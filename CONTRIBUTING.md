# Contributing to Featureful SDK

## Reporting bugs

The following information might help identify and resolve the issue:

* The engine branch (Half-Life steam-legacy, Half-Life current, Xash3D FWGS) you're using.
* The operating system you're running the game on. If you encounter a bug on Android version - check whether it's Android specific before creating the issue, i.e. try reproducing the bug on desktop system and report it as such.
* The minimal reproducible example - the minimum set of files to reproduce the issue on someone else's computer. This might be a small map created specifically to show the problem. Attach the files to the issue post.
* Screenshots and videos (if they're applicable given the issue nature) - attach them to the issue post.
* If the issue is related to the NPC behavior, the [debugging commands](https://freeslave.github.io/halflife-featureful/docs/entity-guide/monsters/#debugging) may give some insight on what's happening.

## Requesting features

You can request some feature to be implemented in Featureful SDK. It's best if you describe the feature in detail. If it's inspired by some other mod or game - provide links, screenshots, basically anything that could help us understand the intentions.

We prioritize helping real projects in development, so provide a link to your mod page on moddb or somewhere else. If you're using Featureful SDK as a sandbox without developing a real project, your feature request might get a much lower priority.

## Making pull requests

If the code you want to be merged into Featureful SDK is based on the work done in some other project, please state this explicitly and provide appropriate links. We want to give proper credits to other authors.
